A tiny Node program that writes exactly one emoji — a hugging face, picked as the one most likely to make a stranger smile — to `entry.txt` in the output directory, and nothing else.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
